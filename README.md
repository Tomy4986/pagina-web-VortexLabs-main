# Pixel Perfect Presence

Quiero que construyas un sitio web profesional, moderno y orientado a conversión para una agencia/emprendimiento que se dedica a crear páginas web profesionales para negocios y emprendimientos.

1. OBJETIVO PRINCIPAL

El objetivo del sitio es conseguir clientes interesados en contratar una página web.

La web debe transmitir:

Profesionalismo

Confianza

Calidad

Modernidad

Tecnología

Cercanía

Claridad en los precios y servicios

El visitante debe entender rápidamente:

Qué hacemos.

Qué problemas solucionamos.

Qué servicios ofrecemos.

Cuánto cuestan aproximadamente.

Cómo es el proceso de trabajo.

Qué ejemplos de trabajos podemos mostrar.

Cómo contactarnos.

El principal objetivo de conversión debe ser que el usuario nos contacte por WhatsApp.
